The OHS Remote frontend is a single-page React 18 application built with Vite 5 (using the `@vitejs/plugin-react-swc` plugin) and written in TypeScript against a deliberately lax `tsconfig.json` (`noImplicitAny: false`, `strictNullChecks: false`). Routing is client-side via `react-router-dom` v6; server state uses `@tanstack/react-query` v5; styling is Tailwind CSS 3 on top of CSS variables with shadcn/ui (Radix primitives) as the component library; animation is `framer-motion`; icons are `lucide-react` exclusively; toasts are `sonner`. The canonical package manager is **npm** — the repo contains both `package-lock.json` (current) and a stale leftover `bun.lockb` that should be ignored; do not run `bun install`. No Node version is pinned in the repo (there is no `.nvmrc`, no `engines` field, no `.tool-versions`); the project targets **Node 20 LTS**. The dev server command is `npm run dev`, which starts Vite on **port 8080** (hardcoded in `vite.config.ts:10`, not the Vite default 5173). The production build command is `npm run build` (output in `dist/`), with `npm run build:dev` available for a development-mode build with source maps. Tests run via `npm run test` (Vitest, one-shot) or `npm run test:watch` (Vitest watch mode) using jsdom and `@testing-library/react`; note that the test suite currently contains only a single placeholder (`src/test/example.test.ts`) and there is no CI, no Dockerfile, no `.env*` files, and no typecheck script (use `npx tsc --noEmit` for type checking). Lint runs via `npm run lint` (ESLint 9 flat config with `typescript-eslint` + `react-hooks` + `react-refresh` plugins).
